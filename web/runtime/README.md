# Vendored runtime files

A pristine copy of `runtime/tutor` from this repo's pinned `helix/<version>`
snapshot (helix's own tutorial text). `session.rs` embeds it via
`include_str!` and seeds it into the virtual file system at boot, at the
path `helix_loader::runtime_file("tutor")` resolves to on wasm32, so the
built-in `:tutor` command finds it.

Do not edit this file; re-copy it from the new `helix/<version>` snapshot
when bumping the helix tag.

The tutor text is helix's own (MPL-2.0, the same license as this repo), so
it needs no entry in `../NOTICE.md` — that file covers the differently
licensed grammar C sources.
